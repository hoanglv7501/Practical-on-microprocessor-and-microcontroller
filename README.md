# Practical Microprocessor and Microcontroller Lab (ATmega328P)

This repository contains C/C++ embedded software implementations for the **ATmega328P** microcontroller (Arduino Uno hardware layer). The labs demonstrate peripheral interfacing, register-level manipulation, hardware interrupts, timers, ADC processing, serial protocols (UART, I2C), and task scheduling.

---

## 📂 Repository Layout

```text
